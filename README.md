# Hi, I'm David

I'm not just designing screens anymore. I'm crossing over into a full stack
product designer and creative director, and I build the AI agents and skills
behind the work.

Everything here comes out of DavidOS, my personal operating system: the
agents and skills I run every day. When one is useful beyond me, I clean it
up, test it and share it.

## What I've shared

- **[security-scan-agent](https://github.com/skeltonmedia/security-scan-agent)**
  Gives your AI assistant evidence about your machine and projects before it
  recommends a security fix. Read-only, offline by default, tested on Linux,
  macOS and Windows.
- **[design-taste-skills](https://github.com/skeltonmedia/design-taste-skills)**
  Teach an AI assistant your design taste so its work stops looking like
  generic AI.
- **[brand-writing-skills](https://github.com/skeltonmedia/brand-writing-skills)**
  Make AI-assisted writing sound like a person.
- **[football-picks-agent](https://github.com/skeltonmedia/football-picks-agent)**
  A betting agent that runs on live data every day and keeps an honest
  record. It does not win yet.
